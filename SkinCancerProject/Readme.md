# 🧠 تشخیص سرطان پوست با هوش مصنوعی
**SkinCancerProject**

![Prediction UI](https://github.com/bitavafaei/AI-in-Skin-Cancer/raw/main/SkinCancerProject/PredictionUi.png)

## 📌 معرفی پروژه
این پروژه با هدف **تشخیص و طبقه‌بندی سرطان پوست با استفاده از هوش مصنوعی و یادگیری عمیق** توسعه داده شده است.  
در این پروژه با بهره‌گیری از **پردازش تصویر پزشکی** و **شبکه‌های عصبی کانولوشنی (CNN)** تلاش شده است تا یک سامانه هوشمند برای کمک به تشخیص زودهنگام سرطان پوست طراحی شود.

این پروژه بیشتر **کاربرد پژوهشی و آموزشی** دارد و یک زنجیره کامل از مراحل زیر را پوشش می‌دهد:
- پیش‌پردازش تصاویر پزشکی
- آموزش مدل یادگیری عمیق
- ارزیابی عملکرد مدل
- پیش‌بینی نوع ضایعه پوستی

---

## 🎯 اهداف پروژه
- طراحی یک سیستم هوشمند برای تشخیص سرطان پوست از روی تصاویر
- افزایش دقت و سرعت تشخیص نسبت به روش‌های سنتی
- نمایش کاربرد عملی هوش مصنوعی در حوزه پزشکی
- ایجاد بستری برای توسعه و تحقیقات بیشتر در حوزه سلامت دیجیتال

---

## 🧪 داده‌ها (Dataset)
در این پروژه از تصاویر ضایعات پوستی استفاده شده است که شامل نمونه‌های:
- خوش‌خیم (Benign)
- بدخیم (Malignant)
لینک kaggle:
https://www.kaggle.com/datasets/hojjatk/mnist-dataset
> ⚠️ **توجه:**  
> داده‌ها صرفاً برای اهداف تحقیقاتی استفاده شده‌اند و این پروژه **جایگزین تشخیص پزشکی تخصصی نیست**.

---

## 🧠 مدل و روش کار
- استفاده از شبکه‌های عصبی کانولوشنی (CNN)
- پردازش تصاویر ورودی (تغییر اندازه، نرمال‌سازی و ...)
- آموزش مدل با داده‌های آموزشی
- ارزیابی مدل با داده‌های آزمون
- تحلیل معیارهایی مانند دقت (Accuracy) و خطا (Loss)
